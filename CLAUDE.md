# Rules for Claude

## Email and outbound messages: never send without explicit approval

- Never send an email, reply, or any outbound message (Gmail or any other channel) unless the user has explicitly approved that exact final version in the current conversation, with words like "send it", "go ahead and send", or "approved".
- Drafting, revising, and showing drafts is fine. Sending is not, until approval is given.
- Before asking for approval, show the complete final text in the chat (not just a link), including recipients and subject.
- If the user is still reviewing, editing, or debating a draft, do not send. Do not infer approval from urgency or general instructions like "let's get it out". When in doubt, ask.
- Approval covers only the version that was shown. Any later change needs fresh approval.
